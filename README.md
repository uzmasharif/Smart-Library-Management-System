# Smart Library Management System

A web-based Library Management System developed for Karakoram International University (KIU).

## Project Overview

This system helps manage library books, students, borrowing, returning, and library records through a user-friendly web application.

## Features

- Admin and Student Login
- Student Registration
- Add, Edit, Delete and Search Books
- Student Management
- Issue and Return Books
- Book Availability Tracking
- Overdue Books Records
- Library Reports and Statistics
- AI-Based Book Recommendations
- Password Hashing
- CSRF Protection

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git and GitHub

## Installation

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   `pip install -r requirements.txt`

4. Create a `.env` file in the project root.
5. Add your own SECRET_KEY to the `.env` file.
6. Run the application:

   `python app.py`

7. Open http://127.0.0.1:5000 in your browser.

## Project Structure

- app.py - Main Flask application
- create_admin.py - Admin account setup
- recommendation.py - Book recommendation logic
- database/ - Database configuration
- templates/ - HTML templates
- static/ - CSS, JavaScript and images
